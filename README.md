An embedded real-time control system designed to maintain a levitating ping-pong ball at a dynamic target height, dictated in real-time by the position of a user's hand. 

Built on the **STM32F446RE (ARM Cortex-M4)**, this project deliberately bypasses standard blocking HAL functions in favor of a **bare-metal register manipulation** approach to guarantee strict deterministic execution times for the aerodynamic control loop.

## 🚀 Engineering Highlights
* **Bare-Metal Interrupt Architecture:** Utilizes EXTI lines and hardware timers (TIM6) for asynchronous, non-blocking ultrasonic time-of-flight measurements.
* **Non-Blocking Telemetry:** Implemented a custom USART2 transmission routine via the TXE interrupt, completely decoupling the 115200 baud serial output from the PID execution time.
* **Advanced PID Control:** Features a discrete PID controller ($DT = 0.06s$) enhanced with Clamping Anti-Windup and Derivative-on-Measurement (Anti-Kick) to manage aerodynamic turbulence and sudden setpoint changes.
* **Signal Processing:** Integrates an Exponential Moving Average (EMA, $\alpha = 0.2$) discrete filter to mitigate high-frequency acoustic noise from the physical tube.

## 🛠️ Hardware Setup
* **MCU:** STM32 Nucleo-F446RE 
* **Sensors:** 2x HC-SR04 Ultrasonic Proximity Sensors (Feedback & Setpoint)
* **Actuator:** 5015 12V DC Centrifugal Blower Fan
* **Driver:** TB6612FNG Dual Motor Driver (MOSFET H-Bridge)
* **Power Management:** LM2596 DC-DC Buck Converter (12V to 5V logic isolation)

## 🧠 Software Architecture

### The Finite State Machine (FSM)
To ensure system safety and logical transitions, the control loop is governed by an FSM:
1. **Idle State:** Engages when no hand is detected for 5 consecutive cycles. Cuts motor power and resets the PID integral memory to prevent windup upon restart.
2. **Kickstart State:** Applies maximum thrust ($PWM = 999$) when the ball is resting at the bottom of the tube to overcome static friction.
3. **Tracking State:** The standard free-flight mode where the PID dynamically tracks the user's hand position inverted geometrically.

### Time Management & Actuation
* **Microsecond Timebase (TIM6):** Configured via direct register manipulation to run exactly at 1 MHz, serving as a high-precision stopwatch for acoustic flight times.
* **PWM Generation (TIM3):** Configured in PWM Mode 1 to output a 2 kHz control wave. The PID directly updates the `CCR1` capture/compare register to modulate the fan's duty cycle.

## 📊 Performance Evaluation
The embedded telemetry data is exported directly to MATLAB for real-time evaluation. The system demonstrates strong setpoint tracking with a physiologically acceptable phase delay and effectively prevents derivative kicks during sharp target variations.

## 🔮 Future Developments
* Migration from ultrasonic to Time-of-Flight (ToF) optical sensors (e.g., VL53L0X) to eliminate acoustic interference inside the tube.
* Implementation of advanced control strategies such as Model Predictive Control (MPC) based on a mathematical model of the physical plant.
